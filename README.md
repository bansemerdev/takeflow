# TakeFlow

Sistema interno de gerenciamento de projetos audiovisuais desenvolvido em Python.

## Sobre o projeto

A aplicação tem como objetivo permitir o registro e acompanhamento dos projetos desde a fase de estudo e desenvolvimento até sua produção, reunindo informações sobre orçamento, necessidade de financiamento, origem dos recursos e andamento de cada produção.

O sistema está sendo desenvolvido progressivamente em Python, começando por uma aplicação de terminal e evoluindo conforme novos conceitos e tecnologias são implementados.

## Funcionalidades atuais

- Cadastro de projetos audiovisuais
- Contagem de projetos cadastrados
- Registro de horas trabalhadas por projeto
- Registro do valor recebido por projeto
- Cálculo do faturamento total
- Cálculo do valor médio por projeto
- Validação de dados inseridos pelo usuário
- Geração de relatório dos projetos cadastrados
